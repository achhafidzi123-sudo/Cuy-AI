ℹ️ Tentang Cuy AI

Cuy AI nyari data dari Semantic Scholar, CrossRef, arXiv, dan Internet Archive secara langsung lewat browser kamu — nggak ada server tambahan, nggak ada data kamu yang disimpan di luar.

Ringkasan & kata kunci dibuat otomatis dari abstrak (metode ekstraktif), bukan ditulis ulang oleh model bahasa generatif.

⚠️ Lagi jalan di mode pratinjau: koneksi keluar diblokir di tempat ini, jadi hasil yang tampil adalah data contoh (dummy), bukan data asli. Download file ini dan buka langsung di browser (atau hosting di GitHub Pages/Netlify) biar pencariannya ambil data nyata dari internet.
